# Secure LLM Gateway

Policy-controlled LLM gateway with deterministic fallback and metadata-only auditing.

It demonstrates one thing: when an approved primary model hits a rate limit, the gateway fails over **only** to a fallback that the server has configured and the active profile allows — and it never reroutes on authentication, policy, or quota failures. Prompts and outputs are never written to the audit log.

> **Boundary:** this is a prototype for synthetic code and mock data. It must not be used to bypass corporate AI policy, Copilot controls, or provider quotas. See [`SECURE_LLM_GATEWAY_PLAN.md`](SECURE_LLM_GATEWAY_PLAN.md) and [`docs/security-review-checklist.md`](docs/security-review-checklist.md).

## Profiles

| Profile | Where | Default route (primary → fallback) | Needs |
|---|---|---|---|
| `mock` (default) | Corporate or any machine | `mock` → `mock_fallback` | Python 3.11+ only. No network, no model server, no API key. |
| `local` | Personal computer | `mock` → `ollama` | Ollama running locally; optionally ChromaDB (`.[local]`) and Docker for Floci. |
| `enterprise` | Company-managed only | `enterprise` → none | Fails closed until a company-approved endpoint is configured. |

Unknown profile values are rejected at startup.

## CLI

| Command | What it does |
|---|---|
| `python -m app.cli demo --provider mock` | Primary success, simulated 429 → fallback, fallback failure, 401 with no fallback, then the audit trail. |
| `python -m app.cli audit-report` | Success metrics from the audit database (plan §13). |
| `python -m app.cli rag-demo` | Retrieval over `sample_project/` (needs `ENABLE_RAG=true` and `.[local]`). |
| `python -m app.cli floci-demo` | Exports one synthetic audit event to a local Floci S3 emulator (`local` profile, `ENABLE_FLOCI=true`). |

## HTTP API

```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

| Endpoint | Purpose |
|---|---|
| `GET /health` | Profile, configured route, allowlists, whether simulation is enabled. |
| `POST /v1/generate` | Route a request. Body: `prompt`, `model`, `data_classification`, `use_rag`, and (when simulation is enabled) `simulate_primary` / `simulate_fallback`. |
| `GET /v1/audit` | Recent metadata-only audit events. |
| `GET /v1/metrics` | Aggregated metrics. |

The request body **cannot** choose providers or request IDs — unknown fields such as `primary_provider`, `fallback_provider`, or `request_id` are rejected with HTTP 422. Routes come from server configuration and request IDs are generated by the gateway.

> The API has no caller authentication yet. Bind it to `127.0.0.1` only.

## Configuration

Copy `.env.example` to `.env` (ignored by Git) or set environment variables directly.

| Variable | Default | Notes |
|---|---|---|
| `APP_PROFILE` | `mock` | `mock`, `local`, or `enterprise`. |
| `PRIMARY_PROVIDER` / `FALLBACK_PROVIDER` | profile route | Optional override; still checked against the profile allowlist. `FALLBACK_PROVIDER=none` disables fallback. |
| `ALLOW_SIMULATION` | on for `mock`/`local`, off for `enterprise` | Enables the `simulate_*` fault-injection fields. Cannot be enabled in `enterprise`. |
| `ENABLE_RAG` | `false` | Requires `pip install -e ".[local]"`. |
| `ENABLE_FLOCI` | `false` | `local` profile only; endpoint must be `localhost`/`127.0.0.1`. |
| `OLLAMA_BASE_URL` / `OLLAMA_MODEL` | `http://localhost:11434` / `qwen2.5-coder:7b` | `local` profile. |
| `AUDIT_STORE` / `AUDIT_DB_PATH` | `sqlite` / `./data/audit.db` | `memory` keeps nothing on disk. |
| `FALLBACK_ON_QUOTA_EXHAUSTED` | `false` | Fall back on 402 / 429 `insufficient_quota` only when an alternative budget is approved. |
| `OPENAI_COMPAT_BASE_URL` / `_MODEL` / `_API_KEY` | unset | External OpenAI-compatible API (`openai_compat`, `local` profile). HTTPS only; the configured model is always used. |
| `OLLAMA_API_KEY` / `OLLAMA_CA_BUNDLE` / `OLLAMA_ALLOW_PLAINTEXT_TUNNEL` | unset / unset / `false` | Remote Ollama: private or tunnel address only, token required, HTTPS unless the tunnel is confirmed. |

## Routing rules

- **Fallback allowed:** HTTP 429 rate limit and HTTP 503 temporary unavailability — only to the configured fallback, and only if the profile allowlists it.
- **Never rerouted:** 401/403 authentication, other 4xx such as content-policy rejections, malformed provider responses, policy denials (provider, model, data class, secrets in prompt, RAG disabled, simulation disabled, endpoint denied), and unknown errors.
- **Budget exhaustion** (402 / 429 `insufficient_quota`): not rerouted unless `FALLBACK_ON_QUOTA_EXHAUSTED=true`.
- **Remote self-hosted models** must sit on a loopback, private or tunnel address, behind a token, over HTTPS (or a confirmed WireGuard/Tailscale tunnel). Public addresses are refused.
- **Always denied:** `personal_api`.
- At most one fallback attempt per request — no retry loops.

## Repository layout

```text
app/            gateway: config, policy, router, audit, CLI, HTTP API
app/providers/  mock, ollama (local), enterprise (fails closed)
```
